# xiao-music 播放文字接口抓包文档

## 一、项目是什么

**xiaomusic**（容器 `xiaomusic`，镜像 `hanxi/xiaomusic`）是一个把**小爱音箱**改造成网络音乐播放器的开源项目。

核心原理：小爱音箱本身只认小米云的指令，xiaomusic 扮演一个"中间人"——

1. 你从网页控制台选歌；
2. 服务端把音乐（本地文件 / yt-dlp 下载 / 在线音乐源）准备好，或生成 TTS 语音；
3. 服务端调用**小米云 IoT 接口**，让音箱去拉取 `http://<你的主机>:58090/music/xxx.mp3` 播放；
4. 音箱通过 HTTP 直接向 xiaomusic 请求音频流。

所以它既是"遥控器"（发指令），又是"音频服务器"（供流）。语音口令、定时任务、DLNA 推送等都在此之上。

当前设备：小米AI音箱，型号 `S12A`，`miotDID = 123456789`，`deviceID = 00000000-0000-0000-0000-000000000000`。

## 二、故障原因与修复

### 现象
网页控制台点「播放文字」按钮无任何反应，音箱不出声。

### 根因（链路逐层定位）
| 环节 | 现象 |
|---|---|
| 前端按钮 | 正常发出了请求 `GET /playtts?text=...&did=...`，服务端也返回 200 |
| edge-tts 合成 | **失败**：`WSServerHandshakeError: 403, Invalid response status` |
| 生成的 mp3 | **0 字节**（`/app/music/tmp/*.mp3` 全部为 0 字节） |
| 音箱拉流 | `GET /music/tmp/xxx.mp3` 返回 **416**（空文件，Range 不可满足） |
| 结果 | 时长判定 0 秒 → 直接跳过 → 无声 |

关键点：**接口没坏，是 TTS 合成坏了**。微软 Edge TTS 服务端把鉴权令牌从 `Sec-MS-GEC-Version: 1-xxx` 升级到了 `2-xxx`，并改写了令牌算法；容器内 `edge-tts 7.2.8` 仍发 v1 令牌，因此 WSS 握手一律 403。

排查中已排除：容器时钟偏差（与宿主机一致）、DNS 污染（`speech.platform.bing.com` → 150.171.27.10 正常）、token 失效（同 token 的 HTTPS 语音列表接口返回 200）、代理缺失（容器直连）。

### 修复
将 `edge-tts` 从 `7.2.8` 升级到 `7.3.1`（新版本使用 v2 令牌）。为让修复在容器重建后依然生效，构建了派生镜像：

- Dockerfile：`C:\docker-data\xiaomusic\Dockerfile`
- 新镜像：`hanxi/xiaomusic:tts-fixed`
- 容器已用该镜像重建，配置完全沿用（端口 `58090:8090`、`TZ=Asia/Shanghai`、`conf` 与 `music` 目录挂载、`--restart always`）
- 旧容器保留为 `xiaomusic-old`（已停止），确认无误后可删除

### 验证结果
| 指标 | 修复前 | 修复后 |
|---|---|---|
| TTS 音频时长 | 0 秒 | 2.88 秒 |
| mp3 文件大小 | 0 字节 | 10~15 KB |
| 音频请求 | 416 | 200 |
| 小米云推送 | code 0（但无音频） | code 0 且正常出声 |

## 三、播放文字接口（抓包）

### 1. 主接口

```
GET /playtts?text=<文字>&did=<设备DID> HTTP/1.1
Host: <你的主机IP>:58090
```

**抓包原文：**

```http
> GET /playtts?text=%E4%BD%A0%E5%A5%BD&did=123456789 HTTP/1.1
> Host: 127.0.0.1:58090
> User-Agent: curl/8.21.0
> Accept: */*

< HTTP/1.1 200 OK
< date: Sat, 31 Oct 2026 15:46:00 GMT
< server: uvicorn
< content-length: 12
< content-type: application/json

{"ret":"OK"}
```

**参数说明**

| 参数 | 必填 | 说明 |
|---|---|---|
| `text` | 是 | 要播报的文字。**必须 URL 编码**（中文、`&`、`#`、`+` 等特殊字符不编码会被截断或报错） |
| `did` | 是 | 音箱的 `miotDID`，本例为 `123456789`。**不是** `deviceID`（UUID 形式，如 `00000000-...`） |

**响应**

| 响应体 | 含义 |
|---|---|
| `{"ret":"OK"}` | 已受理，**异步**播报（立即返回，不代表已播完） |
| `{"ret":"Did not exist"}` | `did` 不存在/未登录 |

**鉴权**：当前 `setting.json` 中 `disable_httpauth: true`，接口**无鉴权**，可直接调用。
若你之后开启了 HTTP 认证，需带上 Basic Auth 头或登录后的 Cookie/JWT。

### 2. 服务端内部时序（同一个点击动作产生的完整链路）

```
① 浏览器  → GET /playtts?text=你好&did=123456789
          ← 200 {"ret":"OK"}                      ← 立即返回

② 服务端  edge-tts 合成 → /app/music/tmp/<md5>.mp3

③ 服务端  → 小米云 play_by_url，告知音箱去拉取
            http://192.168.1.100:58090/music/tmp/<md5>.mp3
          ← {'code': 0, 'message': 'Msg has been successfully proxy to the device...'}

④ 音箱    → GET /music/tmp/<md5>.mp3 HTTP/1.0
          ← 200 音频流

⑤ 服务端  ffprobe 测得时长 → 播完后自动停止（device_player 定时器）
```

日志对照：

```
device.py:117: tts 123456789 你好
device_player.py:943: 使用 edge-tts 生成语音: 你好, voice: zh-CN-XiaoyiNeural
device_player.py:955: TTS 播放 URL: http://192.168.1.100:58090/music/tmp/xxx.mp3
device_player.py:947: TTS 音频时长: 2.88 秒
```

### 3. 音频流接口（音箱实际拉取的）

```
GET /music/<相对路径> HTTP/1.0
例：GET /music/tmp/b9f0128af6571f285f7b0840af4d2031.mp3
```

- 无需鉴权，支持 Range 请求
- **URL 前缀由 `setting.json` 的 `hostname` 决定**（当前为 `http://192.168.1.100`）
- 因此 `hostname` 必须是**音箱能访问到的局域网 IP**，写 `127.0.0.1` 或 `localhost` 会失败；换了网络环境要同步改这一项

### 4. 相关配套接口

| 接口 | 方法 | 用途 |
|---|---|---|
| `/device_list` | GET | 列出设备，从中取 `miotDID` 和 `hardware` |
| `/getvolume` | GET | 查音量 |
| `/setvolume` | POST | 设音量，body `{"did":"123456789","volume":50}` |
| `/getplayerstatus` | GET | 播放状态 |
| `/playurl?did=&url=` | GET | 播放任意 URL（`url` 参数需 `encodeURIComponent` 编码一次，服务端会 unquote） |
| `/cmd` | POST | 发自定义口令，body `{"did":"...","cmd":"播放歌曲"}`,返回 `{"ret":"OK"}` |
| `/cmdstatus` | GET | 查上条口令执行状态 |
| `/device/stop` | POST | 停止播放，body `{"did":"..."}` |

## 四、调用示例

### curl

```bash
# 中文必须 URL 编码
curl "http://192.168.1.100:58090/playtts?text=%E4%BD%A0%E5%A5%BD&did=123456789"
# → {"ret":"OK"}
```

### Python

```python
import requests
from urllib.parse import quote

BASE = "http://192.168.1.100:58090"
DID = "123456789"

def speak(text: str):
    r = requests.get(f"{BASE}/playtts", params={"text": text, "did": DID}, timeout=15)
    return r.json()

print(speak("你好，这是一条测试播报"))
```

### Node / 前端

```javascript
await fetch(`http://192.168.1.100:58090/playtts?text=${encodeURIComponent("你好")}&did=123456789`);
```

> 注意：项目自带前端 `md.js` 的 `playTts()` 是直接拼接字符串、**没有做 `encodeURIComponent`**。
> 所以输入含 `&`、`#`、`%` 等字符时会被截断——这是原项目的小缺陷，你自己调用时记得编码。

## 五、对外调用（网关）

原生接口无鉴权，任何能访问 58090 的人都能让你的音箱说话。为了给程序一个干净的调用面，
额外加了一层网关容器 `xiaomusic-gateway`，**原生接口完全没动**，网页控制台照常使用。

| 端口 | 服务 | 鉴权 |
|---|---|---|
| 58090 | xiaomusic 原生（控制台 / 原始 API） | 无 |
| **58091** | **网关（TTS 接口 + 新闻服务）** | **无（已关闭）** |

局域网地址：`http://192.168.1.100:58091`

### 鉴权状态

**已关闭**，所有接口直接调用即可，不需要任何令牌。
如需重新开启，启动容器时加 `-e AUTH_ENABLED=1 -e TTS_TOKEN=你的令牌`。

### 调用

```http
POST /tts HTTP/1.1
Host: 192.168.1.100:58091
Content-Type: application/json

{"text": "要播报的文字", "did": "123456789"}
```

```json
{"ok": true, "did": "123456789", "text": "要播报的文字"}
```

也支持 `GET /tts?text=...&did=...`，以及 `GET /devices` 查设备、`GET /health` 探活。

完整说明见 `C:\docker-data\xiaomusic\gateway\README.md`，
现成客户端见工作区 `xiaomusic_tts_client.py`（纯标准库，可直接 `import` 用）。

### 为什么建议用 58091 而不是直连 58090

- 58090 还包含上传/下载/删除音乐、改配置等接口，暴露给程序调用面太大
- 58091 只开放 `播报`、`查设备`、`探活`，以及 `/news` 新闻服务
- 单个播报文字限制 500 字，防止误传超长文本

## 六、数据持久化

配置与音乐都在 C 盘，容器重建不丢：

| 宿主机 | 容器内 | 内容 |
|---|---|---|
| `C:\docker-data\xiaomusic\conf` | `/app/conf` | `setting.json`、`.mi.token`、插件配置 |
| `C:\docker-data\xiaomusic\music` | `/app/music` | 音乐文件、TTS 临时音频 |

容器重建后这两处仍是 `bind` 挂载（`RW=true`），已验证生效。新增的网关容器同样把
`C:\docker-data\xiaomusic\gateway` 挂到 `/gw`，Token 配置也在里面。

## 七、注意事项

1. **接口是异步的**：`{"ret":"OK"}` 只代表受理成功。要确认真的播了，去看日志里的 `TTS 音频时长`，或查 `/getplayerstatus`。
2. **`did` 用 miotDID**（`123456789`），不是 UUID 形式的 `deviceID`。
3. **音箱必须能访问 `hostname`**：跨网段、防火墙、Docker 端口映射任一环节不通，都会表现为"接口 200 但没声音"。
4. **edge-tts 是外部依赖**：微软再次调整鉴权时仍可能失效，届时升级 `edge-tts` 并重新构建镜像即可（Dockerfile 已备好）。
5. **音色**由 `setting.json` 的 `edge_tts_voice` 控制，当前 `zh-CN-XiaoyiNeural`。设为 `disable` 会关闭 TTS；设为空字符串则改走小米云原生 TTS。
6. **不要直接把 58091 映射到公网**：Token 会明文传输。要公网访问，先加 HTTPS 反代或走内网穿透。
